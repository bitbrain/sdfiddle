SDFiddle Shader How-To

Guidance for writing signed distance field shaders inside SDFiddle.

Core Concepts

SDFiddle renders a full-screen quad and passes the standard ShaderToy-style uniforms into your fragment shader. Your job is to write a function that returns a signed distance to the closest surface at each pixel.

  • vec2 fragCoord contains the pixel coordinate being shaded.
  • vec2 iResolution is the viewport size in pixels.
  • float iTime is the elapsed time in seconds since the preview started.
  • vec4 iMouse stores the pointer position and button state.

Shader Structure

The default template creates an entry point compatible with the live preview and export pipeline.

float sdf(vec3 p) {
  // Return the signed distance for point p
  return length(p) - 0.5;
}

vec3 estimateNormal(vec3 p) {
  const vec2 e = vec2(1.0, -1.0) * 0.0005;
  return normalize(vec3(
    e.xyy * sdf(p + e.xyy),
    e.yyx * sdf(p + e.yyx),
    e.yxy * sdf(p + e.yxy),
    e.xxx * sdf(p + e.xxx)
  ));
}

void mainImage(out vec4 fragColor, in vec2 fragCoord) {
  vec2 uv = (fragCoord - 0.5 * iResolution.xy) / iResolution.y;
  // Raymarch, shade, and output color into fragColor
}

Keep mainImage intact—SDFiddle wires it into the preview canvas and exported shader bundle. Feel free to add helpers or include files in the editor as needed.

Uniforms and Inputs

Time and Animation

Use iTime for smooth looping animation tied to seconds. For beat-synced or discrete events, derive state from floor(iTime) or mod operations.

Mouse Interaction

iMouse.xy gives the last pointer position in pixels, while iMouse.zw flips to non-zero values while the primary button is pressed. Normalize by iResolution.xy when mapping to UV space.

Supported Syntax & Limits

SDFiddle compiles your shader as a WebGL 1.0 fragment program targeting GLSL ES 1.00 (OpenGL ES 2.0). Follow the capabilities in the current WebGL 1.0 specification to ensure portability across browsers.

  • Omit #version directives. WebGL 1.0 requires the default 1.00 profile, and higher version strings will fail to compile.
  • SDFiddle injects precision highp float;, a varying vec2 vUv;, and uniforms named iResolution, iTime, iBackground, and iSampleOffset before your code. When preview antialiasing is enabled, it also defines SDF_AA_ON so you can conditionally branch per sample.
  • Keep loop bounds and array indices static when possible. WebGL 1.0 enforces GLSL ES 1.00 restrictions such as compile-time evaluable loop limits (e.g. for (int i = 0; i < 128; ++i)) and tight limits on uniform array indexing.
  • Advanced stages like geometry, tessellation, or compute shaders are unavailable under WebGL 1.0. Stick with fragment-stage techniques that write to gl_FragColor.
  • All core GLSL ES math/library intrinsics are available. For a quick lookup, see the OpenGL ES 2.0 reference pages.

Signed Distance Patterns

Primitives

  • sdSphere(p, r) returns length(p) - r.
  • sdBox(p, b) combines length(max(abs(p) - b, 0.0)) with the inside distance.
  • sdRoundBox(p, b, r) expands edges with a rounded profile.

Boolean Ops

  • Union: min(d1, d2)
  • Intersection: max(d1, d2)
  • Subtraction: max(-d1, d2)

Transform Helpers

  • Translate: call sdf(p - offset).
  • Repeat: p = mod(p, cellSize) - 0.5 * cellSize;
  • Bend/Twist: modify the axis with sine/cosine before sampling the primitive.

Debugging Tips

  • Use a stepped palette based on distance to visualize ray steps or gradients.
  • Animate the camera path with iTime to explore the volume.
  • Export frequently—SDFiddle bundles your shader and settings for reproducible results.

If the preview goes black, check for NaNs, extremely high step counts, or missing fragColor assignment.
